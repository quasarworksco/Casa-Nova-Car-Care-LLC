# Casanova Car Care LLC

Landing page del taller mecánico Casanova Car Care LLC: mecánica general, refrigeración, frenos y electricidad automotriz.

Sitio estático (HTML, CSS y JavaScript sin dependencias), publicado con GitHub Pages.

- `index.html`: contenido
- `css/styles.css`: diseño y animaciones
- `js/main.js`: interacciones; los datos de contacto se editan en `CONFIG` al inicio
- `assets/`: logo e íconos
